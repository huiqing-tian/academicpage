# Sunny academic website

## Preview
Unzip and open index.html in Chrome or Safari. Keep all files together. Internet access loads the custom Google Fonts; fallback fonts work offline.

## Publish on GitHub Pages
Create a public repository named YOUR_USERNAME.github.io. Upload the contents of this folder to the repository root, including .nojekyll (create it in GitHub if hidden). Under Settings > Pages choose Deploy from a branch > main > / (root) and Save.
